集客用の公式LINEまわりの文面の下書きです。サイトには出していません（noindex）。 そのままコピーして、L Message または LINE公式アカウントマネージャーに貼ってください。

リッチメニューの「まずは話を聞いてみる」は、L Message の予約フォーム（s.lmes.jp）へ飛びます。
前半がフォームの中に置く文言、後半が予約のあとに送る文面です。 【　】の中は、送るときに書き換えてください。

A-5　文面ではないが、直したいところ

  • 日付の初期値が今日になっている　プルダウンに 2026 / 09 / 07 が入ったままです。何も選ばずに送ると、今日で予約が入ります。空にしておくほうが安全です。
  • 第2希望が必須　「まずは話を聞いてみる」を押した段階の人に、候補日を2つ出させるのは重い。任意にするか、「第2希望はなくても大丈夫です」を添えるか。
  • 「どの時間でも大丈夫です」を時間帯のいちばん上へ　いまは5番目です。迷っている人がいちばん選びたい答えなので、先頭にあると早く終わります。（欲しい情報が減るので、そこは判断してください）
  • メールアドレスの項目があれば、任意に　LINEの中で完結するので、返事もLINEで届きます。メールを必須にすると、そこで止まる人が出ます。

C-2　届いていないときに見るところ

  • 一斉配信を1本も送っていない　いちばん多い原因。あいさつメッセージは新規の友だちにしか届かない。送信履歴に一斉配信がなければこれ。
  • 宛先の絞り込みで対象が0人　タグを指定したまま、そのタグが誰にも付いていない。配信履歴の送信数を見る。0や1桁ならこれ。
  • 予約したまま下書きで止まっている　L Message と LINE公式アカウントの両方から送れるので、片方で作って確定し忘れることがある。
  • 無料プランの通数切れ　月200通。友だちが200人を超えていると途中で止まる。
