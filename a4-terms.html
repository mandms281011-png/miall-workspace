会員規約

コミュニティワークスペース miall をご利用いただくうえでの、当社と会員のみなさまとの取り決めです。
日々の過ごし方については、別紙「ご利用ルール」にまとめています。

第1条（目的）

本規約は、株式会社Siayell（以下「当社」）が運営するコミュニティワークスペース miall（以下「本施設」）の利用条件および当社と会員との権利義務関係を定めるものです。

第2条（定義）

  1. 「会員」とは、本規約に同意し、当社所定の手続きにより入会の承認を受けた個人をいいます。
  2. 「ゲスト」とは、会員に同伴して本施設を利用する者をいいます。
  3. 「本サービス」とは、本施設およびこれに付随して当社が提供するサービスをいいます。

第3条（利用資格）

  1. 本施設は、更衣・化粧室等の設備の性質および会員が安心して利用できる環境を確保する必要から、女性の方のみを利用対象とします。
  2. 会員は、満18歳以上であることを要します。未成年者の入会には親権者の同意を要します。
  3. 前各項のほか、当社が別途定める基準を満たさない場合、入会をお断りすることがあります。

第4条（入会）

  1. 入会希望者は、当社所定の方法により申し込み、本規約に同意するものとします。
  2. 当社は、申込内容を確認のうえ入会の可否を判断します。当社は理由を開示することなく入会をお断りできるものとします。
  3. 入会金は11,000円（税込）とします。ただし当社が定める期間・条件においては、これを減額または無料とすることがあります。

第5条（会費）

  1. 会費は次のとおりとします（いずれも消費税込）。
    • 月払：16,500円／月（本体15,000円）
    • 年払：178,200円／年（本体162,000円）
  2. 前項のほか、館の運営・イベントの企画運営に継続して関与いただく会員（以下「運営会員」といいます）の会費は、次のとおりとします（いずれも消費税込）。
    • 月払：11,000円／月（本体10,000円）
    • 年払：118,800円／年（本体108,000円）
    運営会員は、当社が個別にご案内した方に限ります。運営会員は、駐車場を無料でご利用いただけます。当社は、関与の状況により、運営会員の区分を通常の会員に変更することがあります。この場合、変更後の会費は、変更を通知した月の翌月分から適用します。
  3. 会費は、当社所定の決済方法（クレジットカード等）により、あらかじめお支払いいただきます。
  4. 現金でのお支払いは、原則としてお受けしておりません。ただし、3ヶ月分をまとめて前納いただける場合に限り、現金でのお支払いに応じることがあります。
  5. 納入済みの会費は、本規約に別段の定めがある場合を除き、返金いたしません。
  6. 会費の支払いが確認できない場合、当社は本サービスの提供を停止し、または会員資格を取り消すことができます。

第6条（利用時間）

本施設の利用可能時間は9:00〜21:00とします。当社は、設備点検・臨時休業等により利用時間を変更することがあり、この場合は事前に会員へ通知します。

第7条（会費に含まれるサービス）

会費には次のものが含まれます。

設備等

  1. 本施設内スペースの利用（回数制限なし）
  2. 電源（コンセント）およびWi-Fiの利用
  3. フリードリンクおよびおやつ（無農薬・オーガニックにこだわったもの）
  4. トレーニングスペースおよびトレーニンググッズの利用
  5. ロッカー、更衣室および冷蔵庫の利用（冷蔵庫は記名のうえ当日限りとします）
  6. プリンター、プロジェクター（4K対応のものを含みます）、スクリーン、モニター、マイクおよび筆記用具の利用
  7. ゲスト1名の同時利用

機会等

  1. 月1回のメンタリング（1回30分・公式LINEにてご予約）
  2. 月1回の miall会への参加資格（飲食をともなうため、参加には別途会費を申し受けます。会費の額は開催ごとに定め、事前にご案内します。ゲストの同伴が可能）
  3. 当社が提供する無料セミナー（オンライン）
  4. 会員による勉強会・セミナーおよび同好会活動への参加

※第8号のメンタリングは月1回・1回あたり30分とし、ご予約は公式LINEにて承ります。担当は当社代表または当社が指定した者とします。会員数が30名を超えた場合、当社はこれをグループ形式（1組4〜5名・60分程度）に変更することがあります。
※miall会の会費、有料セミナー、学びの場（連続講座）、リトリートその他別途参加費を定める企画の費用は、月会費に含まれません。これらには会員価格を設ける場合があります。

第7条の2（同好会）

  1. 会員は、会員3名以上により同好会を結成することができます。
  2. 同好会の活動内容は会員の自主性に委ねられますが、本規約および利用ルールに従うものとします。
  3. 金融・投資を扱う同好会においては、一般的な知識の共有にとどめるものとし、特定の金融商品の推奨、個別の投資判断の助言および勧誘を行ってはなりません。個別の判断は、有資格の専門家または公的窓口にご相談ください。
  4. 当社は、同好会の活動内容および会員間で生じた事項について責任を負いません。

第7条の3（会員紹介特典）

  1. 会員の紹介により本施設の見学または体験利用があった場合、当社は、紹介した会員および紹介を受けた方の双方に、Starbucks eチケット500円分を進呈します。
  2. 前項の特典は、ご紹介の都度進呈します（回数の制限はありません）。ただし、同一の方をご紹介いただいた場合は初回のみとします。
  3. 本特典は、会員間の勧誘行為を推奨するものではありません。相手方が求めていない紹介行為は、第11条第4号に該当する場合があります。

第8条（ゲストの同伴）

  1. 会員は、同時に1名までゲストを同伴して本施設を利用できます。追加の料金は発生しません。
  2. ゲストのみでの利用はできません。
  3. ゲストは第3条第1項の利用対象の定めに従うものとします。
  4. ゲストの行為については、同伴した会員が責任を負うものとし、ゲストが本規約または利用ルールに違反した場合、当該会員の違反とみなします。

第9条（セミナー等の開催および集客）

  1. 会員は、当社の事前の承認を得て、本施設においてセミナー・講座・説明会等（以下「セミナー等」）を開催することができます。
  2. セミナー等において集客を行う場合、参加者名簿に記載のある者に限り本施設を利用できます。
  3. 会員は、開催の2日前までに、日時・内容・参加者名簿を当社に提出するものとします。
  4. 名簿に記載のない者の入館は認められません。
  5. 当社は、内容が第11条各号に該当するおそれがあると判断した場合、開催の承認を取り消すことができます。

第10条（会員の責任）

  1. 会員は、自己の責任において本施設を利用するものとします。
  2. 会員は、本施設内に持ち込んだ物品を自己の責任で管理するものとし、当社は盗難・紛失・破損について責任を負いません。
  3. 会員が本施設の設備・什器を故意または過失により損壊した場合、その損害を賠償するものとします。
  4. 入館用の鍵・カード等の貸与・譲渡・複製はできません。紛失した場合は速やかに届け出るものとし、再発行の実費要記載：金額を申し受けます。

第11条（禁止事項）

会員およびゲストは、本施設において次の行為を行ってはなりません。

  1. 連鎖販売取引（ネットワークビジネス・MLM）の勧誘
  2. 投資・保険・金融商品の勧誘（会員本人の業務として行う場合を含め、他の会員が求めていない場合）
  3. 宗教活動・政治活動および布教・勧誘
  4. 他の会員に対する、相手方が明示または黙示に拒絶している営業行為・勧誘
  5. 他の会員またはゲストへの迷惑行為、誹謗中傷、つきまとい
  6. 他の会員、第三者またはその事業について、誹謗中傷、侮辱その他これに類する言動を行うこと
  7. 他の会員の活動または成果を否定し、見下し、あるいは妨げる言動を継続的に行うこと
  8. 他の会員が写り込む写真・動画を、本人の同意なく撮影または公開すること
  9. 本施設で知り得た他の会員の個人情報・業務上の情報を、正当な理由なく第三者に開示すること
  10. 会員資格の第三者への貸与・譲渡
  11. 本施設を住所・所在地として表示すること（当社が別途認めた場合を除く）
  12. 法令または公序良俗に反する行為
  13. その他、当社が不適切と判断する行為

第12条（違反時の措置）

  1. 会員が本規約に違反した場合、当社は、是正の勧告、利用の一時停止、または会員資格の取消し（強制退会）を行うことができます。
  2. 第11条第1号から第4号までに該当する行為については、当社は催告なく直ちに会員資格を取り消すことができるものとします。
  3. 第11条第6号および第7号に該当する言動については、当社は是正を求めたうえ、なお改善されない場合に会員資格を取り消すことができるものとします。本施設は会員が互いを応援し合う場であることを前提としており、この前提を損なう言動は、他の会員の利益を直接に害するものと位置づけます。
  4. 前各項による資格取消しの場合、納入済みの会費は返金しません。

第13条（退会）

  1. 会員は、退会を希望する月の前月末日までに当社所定の方法で届け出ることにより退会できます。
  2. 届出が期限を過ぎた場合、退会は翌々月の扱いとなり、当月分および翌月分の会費が発生します。

第14条（年払会員の中途退会）

  1. 年払会費は、契約期間の途中でご退会される場合も返金いたしません。ただし、当社の責めに帰すべき事由による場合はこの限りではありません。
  2. 年払会費は、1年間ご利用いただくことを前提とした割引価格であるため、期間の途中でのご退会について日割りまたは月割りによる精算は行いません。
  3. ご退会の届出は、第13条の定めによります。

第14条の2（年払いの更新）

  1. 年払いの契約は、契約期間の満了日の翌日に、同一の条件で1年間、自動的に更新されます。以後も同様とします。
  2. 当社は、契約期間が満了する1ヶ月前までに、更新のご案内を会員へ通知します。
  3. 更新を希望されない場合は、契約期間が満了する月の前月末日までに当社所定の方法でお届けください。届出が期限を過ぎた場合、更新後の契約が成立し、第14条の定めにより会費は返金いたしません。
  4. 更新後の会費を変更する場合、当社は前項の通知においてその金額をお知らせします。

第15条（休会）

当社は、休会制度を設けておりません。

長期にわたりご利用が難しくなった場合は、第13条の定めにより一度ご退会いただき、再開されるときにあらためてご入会ください。この場合、入会金は再度申し受けません。

第15条の2（防犯カメラ）

  1. 当社は、防犯および会員の安全確保を目的として、本施設の入り口および室内に防犯カメラを設置しています。
  2. 更衣室および化粧室には設置していません。
  3. 記録した映像は、前項の目的の範囲でのみ使用し、保存期間は3ヶ月とします。閲覧できる者は、藤澤 美嘉（株式会社Siayell 代表）および当社が指定した担当者に限ります。
  4. 法令に基づく場合または人の生命・身体・財産の保護のために必要な場合を除き、第三者に提供することはありません。

第16条（会員情報の取扱い）

  1. 当社は、会員から取得した個人情報を、本サービスの提供、連絡、および会員向け案内の目的の範囲で利用します。
  2. 当社は、法令に基づく場合を除き、会員の同意なく個人情報を第三者に提供しません。
  3. 第9条に基づき提出された参加者名簿は、本施設の入館管理の目的にのみ使用し、目的達成後は速やかに廃棄します。

第17条（免責）

  1. 当社は、天災地変、設備の故障、通信回線の障害その他やむを得ない事由により本サービスを提供できない場合、これによって会員に生じた損害について責任を負いません。

  3. 当社の責に帰すべき事由により会員に損害が生じた場合であっても、当社の賠償責任は、会員が当社に支払った直近12ヶ月分の会費相当額を上限とします。ただし当社に故意または重過失がある場合はこの限りではありません。

第18条（反社会的勢力の排除）

会員は、自己が暴力団その他の反社会的勢力に該当しないこと、および将来にわたって該当しないことを表明・保証します。これに反することが判明した場合、当社は催告なく会員資格を取り消すことができ、この場合の会費は返金しません。

第19条（規約の変更）

当社は、必要と判断した場合、本規約を変更することができます。変更する場合は、変更後の内容および効力発生日を、効力発生日の30日前までに本施設内の掲示または電子メール等により周知します。

本規約は日本法に準拠します。本サービスに関して紛争が生じた場合、長野地方裁判所を第一審の専属的合意管轄裁判所とします。
